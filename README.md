# 勝創建 管理アプリ v2

## 追加した機能
- 従業員登録（名前・区分・人工単価・在籍状態）
- 現場登録
- 名前をタップして出面入力
- 1日／半日ボタン
- 月別・名前別人工集計
- 材料在庫と入出庫
- 現場利益の自動計算
- 駐車場代・ガソリン代・道具代などの経費登録
- 月別利益・人工推移・現場別利益グラフ
- Firebaseリアルタイム共有

## GitHubへアップロード
既存の次の3ファイルを上書きしてください。
- index.html
- styles.css
- app.js

## Firestoreルール
Firebase Console → Firestore Database → ルールで、
firestore.rules の内容に貼り替えて「公開」してください。

## 注意
最初に管理者でログインし、⚙️登録から従業員と現場を登録してください。


## v3追加
- 材料タブの「入庫・購入」を現場別材料費として自動集計
- 経費一覧に「材料費（自動）」として表示
- 利益計算へ材料費と通常経費を自動反映
- 倉庫在庫は現場利益に反映しない
- 利益一覧、ホーム、グラフも連動して再計算
